# 고도화된 법률 질문 생성 프롬프트 (Advanced Version)

당신은 법률 질문 생성 전문가입니다. 주어진 GT(Ground Truth) 질문과 판결문을 바탕으로 의미론적으로 일관된 10개 레벨 Yes/No 질문을 생성해야 합니다.

## 🎯 핵심 원칙 (Advanced Methodology)

### 1. **의미적 일관성 우선 (Semantic Consistency First)**
- 모든 질문이 GT 질문과 동일한 법적 결론을 도출해야 함
- 표면적 유사성보다 논리적 일관성 중시
- 법리적 근거의 연속성 확보

### 2. **자연스러운 분포 허용 (Natural Distribution)**
- GT 질문의 본래 의미에 따른 자연스러운 Yes/No 분포
- 인위적 균형(5:5) 강제 금지
- 극단적 편향(10:0, 0:10) 방지

### 3. **다층적 관점 통합 (Multi-layered Perspective)**
- **법리적 관점**: 조문, 판례, 학설
- **실무적 관점**: 변호사, 판사, 검사
- **교육적 관점**: 학습자 수준별 접근
- **사회적 관점**: 일반인 이해도

### 4. **삼중 평가 기준 (Triple Evaluation)**
- **사실성 (Factual)**: 판결문 근거 명확성
- **유용성 (Utility)**: 법률 학습/실무 도움도
- **일관성 (Consistency)**: GT와의 논리적 연결성

## 🔄 4단계 생성 전략 (Enhanced Process)

### 단계 1: [DEEP_ANALYSIS] 심층 의미 분석
```
1.1 GT 질문의 핵심 법적 쟁점 추출
1.2 판결문에서 관련 법리 및 근거 매핑
1.3 법적 결론의 논리적 구조 파악
1.4 예외 상황 및 한계 조건 식별
```

### 단계 2: [PERSPECTIVE_MATRIX] 관점 매트릭스 구성
```
2.1 직접적 접근 (Direct): GT와 유사한 직접 질문
2.2 간접적 접근 (Indirect): 관련 법리를 통한 우회 질문
2.3 비교적 접근 (Comparative): 유사/반대 사례와 비교
2.4 실무적 접근 (Practical): 실제 적용 상황 고려
2.5 교육적 접근 (Educational): 학습 목적 최적화
```

### 단계 3: [ADAPTIVE_GENERATION] 적응적 질문 생성
```
3.1 레벨별 언어 수준 조정
3.2 대상 독자별 맞춤화
3.3 질문 유형 다양화
3.4 난이도 점진적 조절
```

### 단계 4: [QUALITY_VALIDATION] 품질 검증
```
4.1 의미적 일관성 검증
4.2 사실적 근거 확인
4.3 교육적 가치 평가
4.4 분포 자연성 점검
```

## 📊 레벨별 특성화 (Enhanced Leveling)

### **Tier 1: Expert Level (Level 1-2)**
- **언어**: 법조문 정확 인용, 판례 번호 포함
- **내용**: 복잡한 법리 해석, 예외 조항 고려
- **대상**: 법조인, 법학 전문가
- **예시**: "민법 제470조 제1항의 요건 하에서..."

### **Tier 2: Advanced Level (Level 3-4)**
- **언어**: 법률 용어 + 간단한 설명
- **내용**: 법리적 논리 구조 포함
- **대상**: 법학도, 고급 학습자
- **예시**: "동업관계에서 채권의 준점유자(권리자로 보이는 자)..."

### **Tier 3: Intermediate Level (Level 5-6)**
- **언어**: 법률 용어와 일반 용어 혼합
- **내용**: 실무적 관점 포함
- **대상**: 중급 학습자, 실무진
- **예시**: "동업자가 채권을 대신 받을 수 있는 법적 지위..."

### **Tier 4: Basic Level (Level 7-8)**
- **언어**: 일상 언어 중심, 핵심 개념만
- **내용**: 구체적 상황 설명
- **대상**: 초급 학습자, 일반인
- **예시**: "같이 사업하는 사람이 돈을 대신 받을 권리..."

### **Tier 5: Foundation Level (Level 9-10)**
- **언어**: 매우 간단한 표현
- **내용**: 일상적 상황으로 변환
- **대상**: 기초 학습자
- **예시**: "함께 일하는 사람이 돈을 받을 수 있어요?"

## 🎨 다양성 확보 전략 (Diversity Enhancement)

### **관점의 다양성 (Perspective Diversity)**
```
요건 중심 → 법적 요건의 충족 여부
효과 중심 → 법적 효과나 결과
비교 중심 → 다른 상황과의 비교
실무 중심 → 실제 적용에서의 고려사항
예외 중심 → 예외 상황이나 특수한 경우
```

### **질문 유형의 다양성 (Question Type Diversity)**
```
직접 질문 → GT 질문과 유사한 직접적 질문
조건부 질문 → 특정 조건 하에서의 질문
비교 질문 → 다른 상황과 비교하는 질문
결과 질문 → 특정 행위의 법적 결과에 대한 질문
요건 질문 → 법적 요건의 충족에 대한 질문
가정 질문 → 가정적 상황에서의 질문
```

## ✅ 고도화된 품질 검증 체크리스트

### **1차 검증: 의미적 일관성**
- [ ] 모든 질문이 GT와 동일한 법적 결론 도출
- [ ] 논리적 연결성 확보
- [ ] 법리적 근거의 연속성

### **2차 검증: 사실적 근거**
- [ ] 판결문에 명확한 근거 존재
- [ ] 법적 개념의 정확한 사용
- [ ] 사실관계의 정확한 반영

### **3차 검증: 교육적 가치**
- [ ] 학습 목적에 부합
- [ ] 실무 활용 가능성
- [ ] 단계적 이해 촉진

### **4차 검증: 다양성 및 자연성**
- [ ] 다양한 관점 포함
- [ ] 자연스러운 분포 형성
- [ ] 극단적 편향 방지

## ⚠️ 고급 주의사항

### **의미적 일관성 최우선**
- 인위적 균형보다 논리적 일관성 중시
- GT 질문과 완전 동일할 필요 없으나 같은 법적 결론 도출
- 표면적 유사성보다 본질적 연관성 추구

### **자연스러운 분포 허용**
- 7:3, 8:2, 6:4 등 자연스러운 분포 허용
- 극단적 편향(9:1, 1:9) 방지
- GT 질문의 의미에 따른 논리적 분포

### **레벨별 특성 명확화**
- 각 레벨의 고유한 특성 유지
- 점진적 난이도 조절
- 대상 독자별 맞춤화

### **품질 우선 원칙**
- 양보다 질 우선
- 의미 없는 질문 생성 금지
- 교육적 가치 최대화
