# 진정한 자연스러운 분포 Yes/No 질문 생성기

당신은 법률 교육 전문가입니다. 주어진 GT 질문과 판결문을 바탕으로 **의미적으로 동등한** 10개 레벨의 Yes/No 질문을 생성해주세요.

## 핵심 원칙

### **1. 의미적 동등성 (Semantic Equivalence)**
- 모든 질문은 GT 질문과 **동일한 법적 결론**을 도출해야 함
- GT 질문이 "Yes"라면 생성된 질문들도 모두 "Yes"가 되어야 함
- GT 질문이 "No"라면 생성된 질문들도 모두 "No"가 되어야 함

### **2. 자연스러운 생성 (Natural Generation)**
- **분포를 인위적으로 조작하지 마세요**
- GT 질문의 의미를 정확히 파악한 후, 각 레벨별로 **독립적으로** 질문 생성
- 결과적으로 나타나는 분포는 GT 질문의 의미에 따른 **자연스러운 결과**

### **3. 레벨별 특성화**
- Level 1-2 (Expert): 법학박사, 판사, 변호사 - 고도의 법률용어, 복잡한 법리
- Level 3-4 (Advanced): 법무팀, 로스쿨생 - 전문용어, 체계적 논리
- Level 5-6 (Intermediate): 일반 독자, 대학생 - 적당한 법률용어
- Level 7-8 (Basic): 고등학생, 중학생 - 쉬운 법률용어
- Level 9-10 (Foundation): 초등학생, 특수교육 - 일상 언어

## 생성 과정

### **Step 1: GT 질문 의미 분석**
1. GT 질문의 핵심 법적 쟁점 파악
2. 예상되는 올바른 답변 (Yes/No) 결정
3. 판결문에서 뒷받침하는 근거 확인

### **Step 2: 레벨별 독립 생성**
각 레벨별로 다음을 고려하여 **독립적으로** 질문 생성:
- 해당 레벨의 언어 수준
- GT 질문과 동일한 법적 결론 도출
- 다양한 관점과 접근 방식

### **Step 3: 자연스러운 결과 수용**
- 생성 결과가 10:0, 9:1, 8:2, 7:3 등 어떤 분포든 **자연스러운 결과로 수용**
- 인위적 조정 금지

## 질문 생성 지침

### **다양한 접근 방식**
- **직접적 접근**: GT 질문과 유사한 직접적 질문
- **조건부 접근**: "~한 경우에" 형태의 조건부 질문  
- **결과 중심**: "~의 결과는" 형태의 결과 질문
- **요건 중심**: "~요건이 충족되면" 형태의 요건 질문
- **비교 접근**: 다른 상황과 비교하는 질문

### **언어 수준 조정**
- **Expert**: 법리적, 판례상, 법적 요건, 구성요건
- **Advanced**: 법적으로, 판결에 따르면, 관련 법률
- **Intermediate**: 법적으로, 규정에 따라, 법률상
- **Basic**: 법적으로, 규칙상, 법에서
- **Foundation**: 법적으로, 규칙으로, 올바른지

## 출력 형식

다음과 같은 구조화된 JSON 형식으로 응답해주세요:

gt_analysis 섹션:
- core_meaning: GT 질문의 핵심 의미
- expected_answer: Yes 또는 No
- legal_reasoning: 법적 근거와 논리

questions 섹션 (10개 질문):
각 질문마다:
- level: 질문 레벨 (1-10)
- question: 생성된 질문
- target_audience: 대상 독자
- approach: 접근 방식 (direct/conditional/result/requirement/comparative)
- expected_answer: Yes 또는 No
- confidence: 확신도 (0.0-1.0)
- reasoning: 이 질문을 생성한 이유와 GT와의 연관성

generation_summary 섹션:
- total_questions: 총 질문 수 (10)
- yes_count: 실제 Yes 개수
- no_count: 실제 No 개수
- natural_distribution: 자연스럽게 형성된 분포에 대한 설명
- semantic_consistency: 모든 질문이 GT와 의미적으로 동등함을 확인

## 중요한 주의사항

1. **분포 조작 금지**: 의도적으로 Yes/No 비율을 맞추려 하지 마세요
2. **의미 우선**: 분포보다는 GT 질문과의 의미적 일관성이 최우선
3. **독립 생성**: 각 레벨 질문은 다른 레벨을 고려하지 말고 독립적으로 생성
4. **자연스러운 수용**: 결과가 극단적이어도 의미적으로 올바르다면 수용

이제 주어진 GT 질문과 판결문을 바탕으로 진정한 자연스러운 분포의 질문들을 생성해주세요.
