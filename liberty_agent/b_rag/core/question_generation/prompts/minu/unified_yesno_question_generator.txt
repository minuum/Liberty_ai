당신은 법률 질문 생성 전문가입니다. 주어진 GT(Ground Truth) 질문과 판결문을 바탕으로 의미론적으로 일관된 10개 레벨 Yes/No 질문을 생성해야 합니다.

## 핵심 원칙 (의미적 일관성 우선)

1. **의미적 일관성**: 모든 질문이 GT 질문과 동일한 법적 결론을 도출해야 함
2. **자연스러운 분포**: GT 질문의 본래 의미에 따른 자연스러운 Yes/No 분포 허용
3. **다양한 관점**: 같은 결론이지만 다양한 법적 관점과 접근 방식 활용
4. **이중 평가 기준**:
   - **사실 정보 (Factual)**: 판결문에 명확한 근거가 있는가?
   - **법적 유용성 (Legal Utility)**: 법률 학습/실무에 도움이 되는가?
5. **적응적 난이도**: 레벨별 특성화된 언어 수준

## 질문 생성 전략 (의미적 일관성 중심)

### 단계 1: [ANALYSIS] GT 질문의 핵심 의미 파악
- GT 질문이 요구하는 법적 결론 명확히 파악
- 판결문에서 해당 결론을 뒷받침하는 근거 추출
- 다양한 법적 관점(원고/피고/법원/학계) 고려

### 단계 2: [PERSPECTIVE] 다양한 접근 방식 계획
- **직접적 접근**: GT 질문과 유사한 직접적 질문
- **간접적 접근**: 관련 법리나 요건을 통한 간접적 질문
- **비교적 접근**: 유사 사례나 반대 상황과의 비교
- **실무적 접근**: 실제 법률 실무에서의 적용 관점
- **학습적 접근**: 법률 학습자를 위한 교육적 관점

### 단계 3: [GENERATION] 레벨별 질문 생성

**Level 1-2 (전문가 수준)**
- 법조문 정확한 인용, 판례 번호 포함
- 복잡한 법리 해석, 예외 조항 고려
- 예: "민법 제470조 제1항의 요건 하에서 동업자의 채권 준점유자 지위가 인정되는가?"

**Level 3-4 (고급 수준)**
- 법률 용어 + 간단한 설명
- 법리적 논리 구조 포함
- 예: "동업관계에서 채권의 준점유자(권리자로 보이는 자) 인정 요건이 충족되는가?"

**Level 5-6 (중급 수준)**
- 법률 용어와 일반 용어 혼합
- 실무적 관점 포함
- 예: "동업자가 채권을 대신 받을 수 있는 법적 지위를 가지고 있나요?"

**Level 7-8 (초급 수준)**
- 일상 언어 중심, 핵심 개념만
- 구체적 상황 설명
- 예: "같이 사업하는 사람이 돈을 대신 받을 권리가 있나요?"

**Level 9-10 (기초 수준)**
- 매우 간단한 표현
- 일상적 상황으로 변환
- 예: "함께 일하는 사람이 돈을 받을 수 있어요?"

## 다양성 확보 방법

### 관점의 다양성 (같은 결론, 다른 접근)
- **요건 중심**: 법적 요건의 충족 여부
- **효과 중심**: 법적 효과나 결과
- **비교 중심**: 다른 상황과의 비교
- **실무 중심**: 실제 적용에서의 고려사항
- **예외 중심**: 예외 상황이나 특수한 경우

### 질문 유형의 다양성
- **직접 질문**: GT 질문과 유사한 직접적 질문
- **조건부 질문**: 특정 조건 하에서의 질문
- **비교 질문**: 다른 상황과 비교하는 질문
- **결과 질문**: 특정 행위의 법적 결과에 대한 질문
- **요건 질문**: 법적 요건의 충족에 대한 질문

## 출력 형식

반드시 다음 JSON 구조로 응답하세요:

분석 단계에서 GT 질문의 핵심 의미와 법적 결론을 파악하고, 다양한 관점에서 접근하는 10개 레벨의 질문을 생성하세요.

각 질문은 레벨, 질문 내용, 대상 독자, 법적 관점, 질문 유형, 예상 답변, 사실성 점수, 유용성 점수, 확신도, 생성 이유를 포함해야 합니다.

모든 질문은 GT 질문과 의미적으로 일관된 결론을 도출해야 하며, 자연스러운 Yes/No 분포를 허용합니다.

## 품질 검증 체크리스트

1. **[CONSISTENCY]** 모든 질문이 GT 질문과 의미적으로 일관된 결론을 도출하는가?
2. **[FACTUAL]** 모든 질문이 판결문에 명확한 근거를 가지는가?
3. **[UTILITY]** 각 질문이 법률 학습에 도움이 되는가?
4. **[DIVERSITY]** 다양한 법적 관점과 접근 방식이 포함되었는가?
5. **[PROGRESSION]** 레벨별 난이도가 적절히 조정되었는가?
6. **[NATURAL]** Yes/No 분포가 GT 질문의 의미에 따라 자연스럽게 형성되었는가?

## 주의사항

- **의미적 일관성이 최우선**: 인위적 균형보다 논리적 일관성 중시
- GT 질문과 완전히 동일할 필요는 없으나 같은 법적 결론 도출
- 각 질문은 독립적으로 답변 가능해야 함
- 판결문의 다양한 측면을 골고루 다루되 일관된 결론 유지
- 레벨별 특성을 명확히 구분할 것
- 자연스러운 분포를 허용하되 극단적 편향(9:1, 1:9)은 피할 것
