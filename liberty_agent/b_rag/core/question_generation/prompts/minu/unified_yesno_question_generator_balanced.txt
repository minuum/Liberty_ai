🎯 균형잡힌 성능 개선 프롬프트 v3 (분포 편향 해결)

**개선 목표**: 현실적이고 균형잡힌 성능 향상 (90% Yes → 65% Yes)

이 질문을 **균형잡히면서도 적절히 도전적인** 10가지 다른 방법으로 다시 써주세요.

## 🎯 수정된 분포 목표 (중요!)

**분포 편향 문제 해결:**
- **기존 문제**: 90% Yes 답변 (9:1) - 너무 극단적
- **새로운 목표**: 65% Yes 답변 (6-7:3-4) - 현실적이고 자연스러운 분포

## 🔬 개선된 균형 전략

**복잡도 증가 기법 (적당히 활용):**
1. **제한적 조건**: "특정 조건에서만", "일반적으로는"
2. **예외 상황**: "예외적인 경우", "특별한 사정이 있다면"
3. **해석 여지**: "보통은", "원칙적으로는"
4. **관점 차이**: "다른 해석으로는", "반대 의견도 있지만"
5. **시간적 제약**: "현재 상황에서", "향후에는"

## 📊 **핵심 개선사항** - 분포 균형화 (반드시 준수!)

**Level 1-2**: 전문가 질문 + **예외나 제한 조건 명시**
- **반드시 포함**: "예외적으로", "특정 조건하에서", "일반적으로는 아니지만"
- 예: "예외적인 상황에서 특정 조건이 충족되면 인정될 수 있는가?"

**Level 3-4**: 해석적 질문 + **반대 관점 제시**
- **반드시 포함**: "반대 의견도 있지만", "다른 해석으로는", "보통은 아니지만"
- 예: "보통은 인정되지 않지만 이런 경우에는 가능한가?"

**Level 5-6**: 실무적 질문 + **시간적/상황적 제약**
- **반드시 포함**: "현재 상황에서", "실무상으로는", "원칙적으로는"
- 예: "원칙적으로는 어렵지만 실무상으로는 어떻게 적용되나요?"

**Level 7-8**: 일반적 질문 + **조건부 상황**
- **반드시 포함**: "만약에", "경우에 따라서는", "상황에 따라"
- 예: "상황에 따라서는 다르게 판단될 수 있나요?"

**Level 9-10**: 기본 질문 + **자연스러운 의문**
- 단순하지만 자연스러운 의문 표현
- 예: "이런 일이 가능한 건가요?"

## 🎯 **분포 균형화 전략** (핵심!)

**반드시 준수할 분포 규칙:**
- **6-7개 Yes 답변** (60-70%): 원본 의미와 같은 방향
- **3-4개 No 답변** (30-40%): 예외/제한/반대 상황

**Yes 답변 질문 (6-7개):**
- 원본 질문과 같은 결론
- "일반적으로", "보통", "원칙적으로"
- 긍정적 확인, 기본 원칙 적용

**No 답변 질문 (3-4개):**
- 예외 상황, 제한 조건, 반대 관점
- "예외적으로는", "특별한 경우", "제한적으로", "반대로는"
- 제한적 해석, 조건부 부정

## 규칙:
1. 모든 질문은 Yes/No로 답할 수 있어야 합니다
2. 모든 질문의 **기본 법적 원칙**은 원본 질문과 일관되어야 합니다
3. **위의 키워드들을 적극 활용**하여 균형잡힌 분포 달성
4. **6-7개는 Yes 답변, 3-4개는 No 답변**이 되도록 만드세요 (균형 분포)
5. 복잡도: 1번이 가장 복잡하고, 10번이 가장 쉽게

## 🎯 현실적 성공 목표:
- **Standard RAG**: 평균 확신도 0.75-0.80 (자연스러운 수준)
- **Boost RAG**: 평균 확신도 0.85-0.90 (개선된 수준)
- **논문 성과**: 15-20% 성능 향상 (현실적이고 설득력 있음) ✅

- **Yes 유도**: "일반적으로", "보통", "원칙적으로", "통상적으로"
- **No 유도**: "예외적으로", "특별한 경우", "제한적으로", "반대로는"
