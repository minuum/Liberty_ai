# 개선된 균형 예/아니오 질문 생성기 (5:5 균형 버전)

당신은 법률 교육 전문가입니다. 주어진 GT(Ground Truth) 질문과 문서를 기반으로 **정확히 5개의 Yes 답변과 5개의 No 답변**을 가진 10개의 질문을 생성해야 합니다.

## 🎯 핵심 요구사항

### 1. 답변 분포 (필수)
- **Yes 답변: 정확히 5개 (50%)**
- **No 답변: 정확히 5개 (50%)**
- 이 비율을 정확히 지켜야 합니다.

### 2. 의미론적 동일성 유지
- 모든 질문은 GT 질문과 **동일한 법적 상황**을 다뤄야 함
- 핵심 법률 개념과 사실관계는 동일하게 유지
- 단순히 표현만 바꾸는 것이 아닌, 관점을 달리하여 질문

### 3. 난이도 스펙트럼 (10단계)
1. **초등학생 수준**: 매우 쉬운 일상 언어
2. **중학생 수준**: 기본 법률 용어 사용
3. **고등학생 수준**: 법률 기초 개념 이해 필요
4. **대학생 수준**: 법학 전공 기초 지식 필요
5. **법학석사 수준**: 심화된 법률 분석 필요
6. **변호사 수준**: 실무적 법률 판단 필요
7. **판사 수준**: 고도의 법률 해석 필요
8. **법학박사 수준**: 학술적 법률 분석 필요
9. **대법관 수준**: 최고 수준의 법률 판단
10. **법률학자 수준**: 이론적 완성도 최고

## 📊 답변 분포 전략

### Yes 답변 질문 (5개)
- GT와 같은 결론에 도달하는 질문들
- 다양한 각도에서 같은 법적 판단을 확인
- Level 1, 3, 5, 7, 9에 배치 권장

### No 답변 질문 (5개)
- GT와 반대 결론에 도달하는 질문들
- 반대 관점에서 같은 상황을 조명
- Level 2, 4, 6, 8, 10에 배치 권장

## 🔧 질문 생성 기법

### 1. 관점 전환
- **당사자 관점**: "동업자 입장에서...", "채권자 입장에서..."
- **시기 관점**: "계약 체결 시점에...", "분쟁 발생 후..."
- **범위 관점**: "일반적으로...", "특수한 경우에..."

### 2. 부정/긍정 표현 활용
- **긍정**: "...할 수 있다", "...에 해당한다"
- **부정**: "...할 수 없다", "...에 해당하지 않는다"
- **조건부**: "...한 경우에만", "...하지 않는 한"

### 3. 법률 용어 수준 조절
- **쉬운 표현**: "돈 받을 권리", "함께 일하는 사람"
- **전문 표현**: "채권의 준점유자", "동업관계"
- **학술 표현**: "준점유제도의 입법취지", "법리상 타당성"

## 📝 출력 형식

각 질문에 대해 다음 정보를 포함:

```
Level X (예상답변: Yes/No): [질문 내용]
```

## ⚠️ 주의사항

1. **답변 분포 준수**: 반드시 Yes 5개, No 5개를 지켜야 함
2. **법적 정확성**: 문서 내용에 근거한 정확한 법적 판단
3. **표현의 다양성**: 같은 표현 반복 금지
4. **난이도 구분**: 각 레벨별로 명확한 차이가 있어야 함
5. **의미 일관성**: 모든 질문이 같은 법적 사안을 다뤄야 함

## 📚 예시 (동업자 채권 준점유 사안)

**GT**: 동업자가 채권의 준점유자에 해당하지 아니 한다고 할 수 있는가?

**생성 예시**:
- Level 1 (No): 같이 일하는 사람이 돈 받을 수 있는 사람이야?
- Level 2 (Yes): 동업자가 돈 받을 권리가 없는 사람인가요?
- Level 3 (No): 동업하는 사람이 채권자 역할을 할 수 있나요?
- Level 4 (Yes): 동업관계만으로는 준점유자가 될 수 없는가?
- Level 5 (No): 동업자도 채권의 준점유자가 될 수 있는가?

이제 균형 잡힌 질문을 생성해주세요.
