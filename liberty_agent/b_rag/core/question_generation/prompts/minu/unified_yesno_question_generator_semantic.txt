## ⚠️ 절대 금지 사항 - 위반 시 완전한 실패 처리 ⚠️

❌ **절대 하지 말 것:**
1. GT 질문의 핵심 키워드를 제거하지 말 것 (예: "동업자", "채권", "준점유자")
2. "이 법률 문제에서...", "관련 법리에 따라..." 같은 일반적 표현 사용 금지
3. GT 질문과 다른 주제나 상황으로 변경 금지
4. 새로운 조건, 시간, 장소, 당사자 추가 금지
5. 긍정/부정 반전 금지

## 🎯 **MANDATORY: 의미론적 동일성 = 핵심 키워드 보존**

### **핵심 원칙:**
**모든 생성 질문은 GT 질문의 핵심 구성 요소를 반드시 포함해야 함**

**GT 질문 구성 요소 분석 예시:**
- 주체: "동업자"
- 객체: "채권"  
- 관계: "준점유자"
- 행위: "해당하지 아니 한다"
- 질문형: "할 수 있는가?"

**→ 모든 Level에서 이 구성 요소들이 보존되어야 함 (단지 표현만 단순화)**

## 📚 **Few-Shot 예시: 올바른 의미론적 동일성**

### **Example 1:**
**GT:** "동업자가 채권의 준점유자에 해당하지 아니 한다고 할 수 있는가?"

**✅ 올바른 생성:**
- Level 1: "동업자가 민법 제470조상 채권의 준점유자에 해당하지 아니 한다고 볼 수 있는가?"
- Level 3: "동업자가 채권의 준점유자에 해당하지 않는다고 할 수 있는가?"
- Level 5: "동업자가 준점유자에 해당하지 않는다고 할 수 있는가?"
- Level 7: "같이 사업하는 사람이 돈을 받을 권리가 있는 것처럼 보이는 사람에 해당하지 않는다고 할 수 있는가?"
- Level 10: "함께 일하는 사람이 권리가 없다고 할 수 있는가?"

**❌ 잘못된 생성 (절대 금지):**
- "이 법률 문제에서 긍정적인 결론이 도출되는가?" (핵심 키워드 모두 제거)
- "관련 법리에 따라 인정될 수 있는 부분이 있는가?" (완전히 다른 질문)
- "이 상황에서 법적으로 유효한 주장이 가능한가?" (의미 변질)

### **Example 2:**
**GT:** "계약 해제권이 발생하는가?"

**✅ 올바른 생성:**
- Level 1: "민법상 계약 해제권이 발생한다고 볼 수 있는가?"
- Level 3: "계약 해제권이 생긴다고 할 수 있는가?"
- Level 5: "계약을 취소할 권리가 생기는가?"
- Level 7: "약속을 취소할 수 있는 권리가 생기는가?"
- Level 10: "약속을 취소할 수 있는가?"

**❌ 잘못된 생성 (절대 금지):**
- "이 계약에서 법적 문제가 있는가?" (해제권 → 법적 문제로 변질)
- "당사자가 권리를 주장할 수 있는가?" (계약 해제 → 일반적 권리로 변질)

## 🔧 **Level별 변환 규칙 (핵심 키워드 보존 필수)**

### **Level 1-2 (최고 구체성)**
- **핵심 키워드 100% 보존**
- 조문 번호, 법률 용어 추가
- 예: "동업자가 민법 제470조상 채권의 준점유자에..."

### **Level 3-4 (높은 구체성)**  
- **핵심 키워드 100% 보존**
- 조문 번호 제거, 법률 용어 유지
- 예: "동업자가 채권의 준점유자에..."

### **Level 5-6 (중간 구체성)**
- **핵심 키워드 80% 보존**
- 일부 법률 용어 → 일반 용어
- 예: "동업자가 준점유자에..." 또는 "같이 사업하는 사람이 채권의 준점유자에..."

### **Level 7-8 (낮은 구체성)**
- **핵심 키워드 60% 보존**
- 대부분 일반 용어로 변환
- 예: "같이 사업하는 사람이 돈을 받을 권리가 있는 것처럼 보이는 사람에..."

### **Level 9-10 (최저 구체성)**
- **핵심 의미 100% 보존** (표현만 최대 단순화)
- 완전한 일상 언어
- 예: "함께 일하는 사람이 권리가 없다고..." 

## 🔍 **강제 검증 단계**

### **생성 후 필수 체크:**
각 질문에 대해 다음을 확인:

1. **키워드 보존 체크:** GT 질문의 핵심 키워드가 포함되었는가?
2. **의미 동일성 체크:** GT 질문과 정확히 같은 법적 상황을 묻는가?
3. **답변 일관성 체크:** GT 질문과 같은 Yes/No 답변이 나오는가?
4. **추가 정보 체크:** 원래 없던 정보가 추가되지 않았는가?

### **실패 시 재생성:**
위 체크에서 하나라도 실패하면 해당 질문을 다시 생성
