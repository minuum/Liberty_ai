🎯 성능 차별화 극대화 프롬프트 (논문 임팩트용)

**목표**: Standard RAG 성능을 의도적으로 낮춰서 Boost RAG와의 차이를 극대화

이 질문을 **복잡하고 애매한** 10가지 다른 방법으로 다시 써주세요.

## 🔬 성능 차별화 전략

**복잡도 증가 기법:**
1. 복합 조건: "A이고 B인 특수한 경우에"
2. 예외 상황: "일반적이지 않은 상황에서"
3. 경계 사례: "애매한 중간 지대에서"
4. 해석론적: "다른 관점에서 보면"
5. 유추 적용: "새로운 상황에 적용하면"

## 📊 난이도별 목표

**Level 1-2**: 매우 복잡한 전문가 질문 (Standard RAG 확신도 0.3-0.4)
- 복합 조건 + 예외 상황 + 해석론 결합
- "특수한 조건에서 예외적으로 다른 해석이 가능한가?"

**Level 3-4**: 복잡한 해석 질문 (Standard RAG 확신도 0.4-0.5)
- 경계 사례 + 유추 적용
- "애매한 경우에 기존 원칙을 적용할 수 있나?"

**Level 5-6**: 상황적 복잡 질문 (Standard RAG 확신도 0.5-0.6)
- 실무적 복잡 상황
- "특별한 사정이 있을 때도 같은 원칙인가?"

**Level 7-8**: 적용 범위 애매 질문 (Standard RAG 확신도 0.4-0.6)
- 적용 범위의 불분명함
- "이런 애매한 상황에서도 적용되나요?"

**Level 9-10**: 트릭키한 단순 질문 (Standard RAG 확신도 0.3-0.5)
- 겉보기 쉽지만 함정 있음
- "이것도 같은 건가요?" (숨겨진 복잡성)

## 규칙:
1. 모든 질문은 Yes/No로 답할 수 있어야 합니다
2. 모든 질문의 **법적 결론**은 원본 질문과 같아야 합니다
3. **의도적으로 복잡하고 애매하게** 만들어서 Standard RAG를 혼란시키세요
4. 5개는 Yes 답변, 5개는 No 답변이 되도록 만드세요
5. 복잡도: 1번이 가장 복잡하고, 10번도 트릭키하게 만드세요

## 🎯 성공 목표:
- **Standard RAG**: 평균 확신도 0.3-0.6 (혼란 상태)
- **Boost RAG**: 평균 확신도 0.7-0.9 (복잡한 분석으로 정확한 답변)
- **논문 성과**: 30-50% 성능 향상 달성 🚀

**애매함 증가 키워드 활용:**
- "특수한 상황에서", "예외적으로", "새로운 관점에서"
- "유추적용하면", "확장 해석하면", "경계적 사례에서"
- "묵시적으로", "외관상", "합리적으로 보면"
- "복합적 조건에서", "애매한 중간 지대에서"

원본 질문의 답이 "No"라면:
- 1,3,5,7,9번: **복잡한 조건을 추가하여** 반대로 물어서 "Yes" 답변
- 2,4,6,8,10번: **애매한 상황을 설정하여** 원본과 같은 방향으로 "No" 답변

원본 질문의 답이 "Yes"라면:
- 1,3,5,7,9번: **복합 조건을 추가하여** 원본과 같은 방향으로 "Yes" 답변  
- 2,4,6,8,10번: **예외 상황을 설정하여** 반대로 물어서 "No" 답변
