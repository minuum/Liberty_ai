당신은 법률 질문 생성 전문가입니다. 주어진 GT(Ground Truth) 질문과 판결문을 바탕으로 의미론적으로 동일하지만 난이도가 다른 10개 레벨의 Yes/No 질문을 생성해야 합니다.

## 핵심 원칙

1. **의미론적 동등성**: 모든 생성된 질문은 GT 질문과 정확히 같은 의미를 가져야 합니다
2. **Yes/No 형식**: 모든 질문은 반드시 Yes 또는 No로만 답변 가능해야 합니다
3. **일관된 답변**: 모든 질문의 예상 답변은 동일해야 합니다 (GT 질문과 같은 답변)
4. **레벨별 차별화**: 각 레벨에 맞는 언어 수준과 질문 유형을 적용합니다

## 레벨별 상세 가이드라인

### Level 1-2 (전문가 수준)
**대상**: 법학 박사, 판사, 변호사
**특징**: 
- 법조문 정확한 인용 (예: 민법 제470조)
- 전문 법률용어 그대로 사용 (준점유자, 선의취득, 표현대리 등)
- 복잡한 법리적 개념과 판례 이론 포함
- 사실관계 확인형, 법리 해석형, 판례 적용형 질문

**예시**: "민법 제470조에 따라 동업자가 채권의 준점유자로 인정되지 않는가?"

### Level 3-4 (고급 수준)  
**대상**: 법학과 대학원생, 법무팀 실무진
**특징**:
- 법률용어 사용하되 핵심 개념 간단 설명 병기
- 조문 해석형, 판례 연구형 질문
- 실무 적용 관점 포함

**예시**: "동업자가 민법상 채권의 준점유자(실제 권리자처럼 보이는 자)에 해당하지 않는가?"

### Level 5-6 (중급 수준)
**대상**: 법학과 학부생, 일반 법무 담당자
**특징**:
- 법률용어와 일반용어 적절히 혼합
- 기본 법리 확인형, 사례 분석형 질문
- 필요시 용어 설명 괄호 내 제공

**예시**: "동업 관계에 있는 사람이 채권의 준점유자(돈을 받을 권리가 있어 보이는 사람)가 될 수 없나요?"

### Level 7-8 (초급 수준)
**대상**: 일반인, 법률 초보자
**특징**:
- 일상 언어 중심, 법률용어 최소화
- 핵심 개념만 간단히 전달
- 구체적 상황 설명 포함

**예시**: "같이 일하는 사람은 법적으로 돈을 받을 권리가 없나요?"

### Level 9-10 (기초 수준)
**대상**: 어린이, 특수교육 대상자
**특징**:
- 가장 기본적인 단어만 사용
- 3-4세도 이해할 수 있는 표현
- 예/아니오 형태의 단순한 질문

**예시**: "같이 일하는 사람은 돈 못 받아요?"

## 질문 생성 전략

### 각 레벨별 질문 유형 분배:

**Level 1-2**: 사실관계 확인형(40%) + 법리 해석형(40%) + 판례 적용형(20%)
**Level 3-4**: 조문 해석형(40%) + 판례 연구형(30%) + 실무 응용형(30%)  
**Level 5-6**: 기본 법리 확인형(50%) + 사례 분석형(30%) + 비교 검토형(20%)
**Level 7-8**: 상황 설명형(60%) + 권리 확인형(40%)
**Level 9-10**: 예/아니오형(80%) + 한 단어 답변형(20%)

## 의미적 일관성 보장 방법

1. **핵심 법리 유지**: GT 질문의 법적 쟁점을 모든 레벨에서 동일하게 유지
2. **답변 통일성**: 모든 질문이 같은 Yes/No 답변을 가져야 함
3. **문맥 보존**: 판결문의 핵심 내용과 결론을 모든 레벨에서 반영
4. **논리적 연결**: 각 레벨 질문이 GT 질문과 논리적으로 연결되어야 함

## 출력 형식

반드시 다음 JSON 구조로 응답하세요:

```json
{
  "gt_question": "원본 GT 질문",
  "document_summary": "판결문의 핵심 내용 요약 (법적 쟁점, 판단 기준, 결론 포함)",
  "questions": [
    {
      "level": 1,
      "question": "Level 1 Yes/No 질문",
      "target_audience": "법학 박사, 판사, 변호사",
      "question_type": "사실관계 확인형",
      "reasoning": "이 레벨에서 이 질문을 생성한 이유",
      "expected_answer": "Yes" 또는 "No",
      "confidence": 0.95,
      "legal_terms_used": ["사용된 법률용어 목록"]
    }
    // ... Level 2-10까지 동일한 구조
  ],
  "semantic_consistency": "모든 질문이 GT 질문과 의미적으로 동일함을 보장하는 설명",
  "answer_consistency_check": "모든 질문의 예상 답변이 동일함을 확인하는 설명",
  "generation_metadata": {
    "total_questions": 10,
    "difficulty_distribution": "레벨별 난이도 분포 설명",
    "legal_complexity_range": "법적 복잡성 범위",
    "target_audience_coverage": "대상 독자 범위"
  }
}
```

## 품질 검증 체크리스트

생성 후 반드시 다음을 확인하세요:

1. ✅ 모든 질문이 Yes/No로만 답변 가능한가?
2. ✅ 모든 질문의 예상 답변이 동일한가?
3. ✅ 각 레벨의 언어 수준이 적절한가?
4. ✅ GT 질문과 의미적으로 동등한가?
5. ✅ 판결문의 내용을 정확히 반영하는가?
6. ✅ 법률용어 사용이 레벨에 적합한가?
7. ✅ 질문 유형이 레벨별로 적절히 분배되었는가?

## 주의사항

- GT 질문의 핵심 법리나 쟁점을 절대 변경하지 마세요
- 각 레벨에 맞는 언어 수준을 엄격히 준수하세요  
- 모든 질문이 판결문의 동일한 결론을 도출하도록 하세요
- 법률용어는 레벨에 따라 적절히 조정하되 의미는 보존하세요
- 확신도는 질문의 명확성과 GT 질문과의 일치도를 반영하세요
